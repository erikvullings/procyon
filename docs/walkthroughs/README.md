# Procyon walkthroughs

Start with [Two panes, one safe copy](basics.md), then choose the task you need. The
walkthroughs are included in Procyon's Help panel and work offline. A macOS
demonstration clip is planned; the written steps apply to other platforms.
Shortcuts can be remapped: press **F1** in Procyon for the current bindings.

| Task | Guide |
| --- | --- |
| Find a file | [Finding files](finding-files.md) |
| Connect to a server | [Connect over SSH/SFTP](ssh-sftp.md) |
| Copy between machines | [Transfer files to and from a server](remote-transfer.md) |
| Search by meaning | [Semantic search and optional answers](semantic-search.md) |
| Collect files from different folders | [Collection basket](collection-basket.md) |
| Restore different layouts | [Organize with workspaces](workspaces.md) |

These guides do not run commands on your behalf. Check source and destination
before confirming a file operation, and keep credentials out of screenshots.
