# Organize with workspaces

A workspace is a named, restorable arrangement of panes and tabs. It records
locations and view preferences, **not** copies of directory contents. The
directory is read afresh when you return to it; an operation does not stop
merely because you switch workspaces.

1. Open the **Workspace switcher** in the toolbar and create a workspace for
   a recurring task, such as Development or Photos.
2. Arrange the panes and tabs for that task, then switch to another workspace
   to see its own locations and layout. Reopen the original workspace to
   return to its saved arrangement.
3. Rename or delete an arrangement from the switcher when you no longer
   need it. Deleting a workspace does not delete the underlying files.

Favourites remain global so a useful location is available across
workspaces. Recent locations and the collection basket are scoped to the
workspace you were using.
