# Collect files across folders

The basket holds references to files from multiple folders and providers;
adding an item does not copy or move it. Basket contents belong to the
current workspace and survive navigation and restarts.

1. Select a file or folder and use the **Add to basket** toolbar button.
   Navigate elsewhere and add another selection.
2. Open the basket with the adjacent toolbar button. It appears as a tab in
   the active pane, showing each item's source location. While the basket is
   visible, **F5** from the directory pane adds the selection to the basket;
   when it is closed, **F5** means Copy as usual.
3. Select basket entries, open a writable destination in the other pane, and
   choose Copy, Move, or Archive. Check for unavailable or overlapping
   entries before confirming the operation.
4. Remove an entry to stop collecting it, or use **Empty basket** to clear
   all references. Neither action deletes the source files.

See [Organize with workspaces](workspaces.md) if you maintain separate
collections for different tasks.
