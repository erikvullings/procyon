# Find a file

1. Open the folder you want to search from in either pane. Use the toolbar's
   **Find files** action (or the command palette) to search beneath that folder.
2. Enter a name or pattern; use the available search controls when you need
   content matches or narrower results. Review the search scope before running
   a broad recursive search on a remote connection.
3. Open a result to navigate to or inspect it. Use **F3** to view a selected
   file without editing it. Keep a search you repeat often as a saved search.

The ordinary file search works without installing semantic components. To
search indexed documents by meaning instead, see [Semantic search](semantic-search.md).
